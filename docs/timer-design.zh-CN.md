# timtik 计时器设计记录

本文沉淀来自 2026-09-06 的产品讨论，作为 timtik 后续开发的当前上下文。

## 产品目标

`timtik` 是一个可安装、离线可启动的语音节拍计时 PWA。用户打开应用后可通过中文语音启动计时或分钟倒计时；开始前有明确预备，运行中有可配置的节拍和报时，停止时留下秒级记录。

## 已确定的交互

### 启动

- 语音命令：`开始计时`、`开始 N 分钟倒计时`、`停止计时`。
- 不使用文字命令作为降级方式。
- 语音不可用或不方便说话时，提供按钮：开始计时、3/5/15 分钟倒计时预设、自定义分钟数后开始倒计时。
- 每次开始先经过 3 秒预备，连续给出 3 次明显提示音，然后才进入运行状态。

### 运行

- 正向计时显示已过去的时间；倒计时显示剩余时间。
- 每 1 秒一次滴声，可关闭或切换音色。
- 每 5 秒一次嗒声，可关闭或切换音色。
- 每 15 秒一次报时，间隔可配置；正向计时读“X 秒”，倒计时读“剩余 X 秒”。
- 报时提示音与整体音量可配置。
- 倒计时结束时停止、提示并写入记录。

### 停止与记录

- 用户语音“停止计时”、点击停止，或倒计时结束，都会停止运行。
- 每条记录至少包含：模式/停止原因、停止时秒数、当前本地时间（秒级）。
- 记录保存在浏览器 Local Storage，当前最多保留 100 条，并支持清空。

## 技术决策

- 无框架静态 Web PWA：`index.html`、`app.js`、`styles.css`、manifest 与 service worker。
- Web Speech API 用于识别语音；Web Audio API 用于合成滴、嗒和提示铃，避免依赖外部音频资源。
- Web Speech API / 语音识别受浏览器和安全上下文限制；应用应始终保留按钮入口。
- 用 `performance.now()` 计算真实经过时间，避免仅依赖 `setInterval` 产生累计漂移。

## 当前已实现

- PWA manifest、Service Worker、应用图标和离线缓存清单。
- 3 秒、3 声预备。
- 正向计时、分钟倒计时、语音命令和按钮启动。
- 每秒/每 5 秒节拍、可配置报时间隔与音色/音量。
- 语音或手动停止、倒计时结束记录。

## 下一步建议

1. 在真实移动浏览器验证麦克风授权、AudioContext 解锁、后台/锁屏时钟行为与 PWA 安装。
2. 把记录的 `count` 明确拆成 `elapsedSeconds` 与 `remainingSeconds`，便于后续统计。
3. 增加自定义倒计时名称和导出记录。
4. 评估是否需要系统通知或后台运行能力；这需要按 iOS/Android 浏览器能力分别设计，不能假设 Web PWA 可可靠后台报时。
