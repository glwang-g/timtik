# timtik

独立、可安装的语音节拍计时 PWA。

当前需求、交互决定和后续方向见 [计时器设计记录](docs/timer-design.zh-CN.md)。

部署到 `timtik.freexlib.com` 的 GitHub Actions 与服务器配置步骤见 [部署说明](docs/DEPLOYMENT.zh-CN.md)。

## 第一版能力

- 中文命令：`开始计时`、`开始 N 分钟倒计时`、`停止计时`；不使用文字命令。无法语音时，用开始计时、3/5/15 分钟预设或自定义分钟按钮操作。
- 每次开始先进行 3 秒、3 次明显提示音的预备；随后开始计时或倒计时。
- 运行中每秒滴声、每 5 秒嗒声、每 N 秒中文报时；各声音和报时间隔可配置。
- 停止或倒计时结束时，将当前秒数和本地时间保存到浏览器本地记录。
- `manifest.webmanifest` + Service Worker 支持安装和离线启动。

## 本地运行

这是静态应用。用任意静态服务器从本目录提供 HTTPS 或 localhost 服务即可；语音识别通常要求安全上下文，并受浏览器实现限制。
