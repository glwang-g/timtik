# timtik

独立、可安装的语音节拍计时 PWA。

当前需求、交互决定和后续方向见 [计时器设计记录](docs/timer-design.zh-CN.md)。

部署到 `timtik.freexlib.com` 的 GitHub Actions 与服务器配置步骤见 [部署说明](docs/DEPLOYMENT.zh-CN.md)。

## 第一版能力

- 中文命令：`开始计时`、`倒计时 N 秒/分钟`、`停止`；数字支持阿拉伯数字与常用中文数字。无法语音时，用开始计时、3/5/15 分钟预设或自定义分钟按钮操作。
- 首次点击“开始语音”并授权麦克风后持续待命；停止或倒计时结束时会自动关闭。识别到开始命令先经过 3 秒、3 次提示音预备，随后开始。
- 运行中每秒短滴、每 5 秒长滴、每 N 秒中文报时；各声音、音量和报时间隔可配置。中文报时由当前设备浏览器的语音引擎播放，不依赖服务器。
- 可为短滴、长滴、报时铃分别导入本地音频，导入内容保存在浏览器本机。
- 停止或倒计时结束时，将当前秒数或剩余分秒与本地时间保存到浏览器本地记录。
- `manifest.webmanifest` + Service Worker 支持安装和离线启动。

## 最近界面调整

- 主页聚焦计时：声音设置、音频导入和记录通过“声音设置与记录”弹层按需查看。
- 点击“停止并记录”、说“停止”或倒计时结束都会自动关闭麦克风。
- 报时语音由浏览器本地合成，不依赖服务器；若没有声音，请检查浏览器语音/自动播放权限与设备音量。

## 本地运行

这是静态应用。用任意静态服务器从本目录提供 HTTPS 或 localhost 服务即可；语音识别通常要求安全上下文，并受浏览器实现限制。
